## 简介

把每天的心情、事件与睡眠记下来，用颜色和时间轴看出自己的情绪规律。界面走温和的浅色调，适合长期使用而不刺眼。

## 功能

- **情绪记录**：按天记录心情、强度与触发事件
- **标签归类**：给记录打标签，便于回看某一类情绪
- **趋势视图**：按周、按月查看情绪分布变化
- **正向引导**：配合呼吸与放松提示做情绪调节
- **本地优先**：数据留在设备，不做账号体系

## 技术栈

React 18 · Tailwind CSS · Vite ｜ 状态与存储在前端完成

## 快速开始

```bash
git clone https://github.com/aiyangdie/Xin-Qing-Yi-Zhan.git
cd Xin-Qing-Yi-Zhan
npm install
npm run dev
```

构建产物在 `dist/`，可直接静态托管。

## 项目结构

```
src/            页面与组件
src/components/ 记录、趋势、引导模块
public/         静态资源
```
